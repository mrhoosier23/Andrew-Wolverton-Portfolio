WHY THE PAGE RETURNED 404

The uploaded folder was named:
  music lab

The website code and canonical URL use:
  music-lab

GitHub Pages treats those as different paths. A space is not the same as a hyphen.

PUT THIS FOLDER IN THE PUBLISHED BRANCH ROOT EXACTLY AS:
  /music-lab/index.html
  /music-lab/studio.css
  /music-lab/studio.js

The homepage link must be:
  href="music-lab/"

Do not upload it as:
  /music lab/
  /Music Lab/
  /music-lab/music-lab/

Expected live URL:
  https://mrhoosier23.github.io/Andrew-Wolverton-Portfolio/music-lab/
