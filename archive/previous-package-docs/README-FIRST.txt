HOW TO INSTALL

1. Open the real Andrew-Wolverton-Portfolio repository folder on your computer.
2. Make a backup or commit the current state first.
3. Copy the contents of this folder into the repository root.
4. Replace matching HTML, CSS, JavaScript, and Studio Keys files.
5. Merge the included assets folder into the existing assets folder.
6. Do not delete your existing project images, audio, video, PDFs, gallery images, or case-study pages.
7. Commit and push with GitHub Desktop.
