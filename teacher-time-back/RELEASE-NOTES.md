# Teacher Time Back Lab release notes

## 2.1 workflow-first strengthening — September 2026

- Kept the core promise: **Give teachers back time.**
- Repositioned the offer more explicitly as teacher-workflow improvement that uses AI, rather than generic AI professional development.
- Kept one flagship build: the Weekly Lesson Setup Assistant.
- Added UDL/accessibility and downstream teaching-material support inside the flagship workflow instead of creating new modules.
- Added a clear **Bring the messy version** message so teachers can start from objectives, notes, old materials, screenshots, links, rough ideas, or unfinished slides.
- Added family communication as a short transfer example: clarify → protect exact details → draft → verify → teacher review → school language-access process.
- Added a visible NYC-specific **Teacher-facing by design** section tied to current NYC Public Schools AI guidance.
- Made **minutes recovered per teacher per week** the primary pilot outcome, with correction and review time included.
- Added reuse rate, teacher control, output quality, and safety/review habits as secondary measures.
- Expanded the 90-minute lab from six broad steps to eight timed moves while keeping the workshop at 90 minutes.
- Preserved the founding-pilot price and the existing school-readiness and student-data boundaries.
