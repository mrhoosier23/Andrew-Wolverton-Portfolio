# Weekly Lesson Setup Assistant Flagship Demonstration

This package is the approved demonstration layer for the Teacher Time Back Lab. It shows the complete story a beginner teacher and a school leader need to see before the webpage or participant PDFs are rebuilt.

## What is inside

- `source/weekly-lesson-demo.json`: canonical demonstration content for documents, website interactions, and future platform adapters.
- `output/docx/Teacher-Time-Back-Flagship-Demonstration.docx`: complete, Google Docs-compatible walkthrough.
- `output/docx/Weekly-Lesson-Setup-Practice-Input.docx`: the ready-made practice example handed to participants.
- `output/docx/Weekly-Lesson-Setup-Assistant-Completed-Setup.docx`: the one-page finished assistant setup shown as proof.
- `assets/`: web-ready PNG and WebP visuals for the four-state website walkthrough.

## The demonstration sequence

1. See the teacher's rough weekly notes and blank format.
2. See the five-part saved assistant instructions.
3. Inspect the first result, including one factual mistake and visible missing-information markers.
4. Watch the teacher correct the result, complete the missing decisions, and save the reusable setup.

The practice materials contain no real people or records. The assistant prepares. The teacher decides.
