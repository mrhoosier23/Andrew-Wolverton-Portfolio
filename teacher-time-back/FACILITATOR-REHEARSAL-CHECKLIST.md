# Teacher Time Back Lab: Facilitator Rehearsal Checklist

Complete one uninterrupted rehearsal before the first school-facing conversation and again before each live pilot.

## Setup check

- Open the school-named AI tool using the exact staff account teachers will use.
- Confirm the account can save or reuse instructions in the way the lab demonstrates.
- Confirm the room, projector, audio, internet, accessibility needs, and participant laptops.
- Keep the PDF practice pack, workbook, and safety card available offline.
- Keep a paper/demo route ready if the school has not confirmed the tool or access fails.
- Record the school’s escalation contact and local guidance link.

## 90-minute run-through

- 0-10: Show the finished Weekly Lesson Setup Assistant and name the promise: one useful assistant for one recurring task.
- 10-20: Help participants choose a small, repeated task that is easy to review.
- 20-30: Confirm the exact school-named tool and staff account. Explain why code names are not automatic de-identification.
- 30-55: Build the five-part setup: help me with, use only, return, stop and ask if, I will review.
- 55-75: Use the supplied practice pack, reveal the planted mistake, correct it, and improve the saved setup.
- 75-85: Run the four-question safety rehearsal.
- 85-90: Save the assistant and define the two-week keep, revise, or stop measure.

## Rehearsal evidence

- The finished example can be demonstrated from start to review in under seven minutes.
- Every screen, link, file, and interaction works on the presentation device.
- Instructions can be understood without the words prompt engineering, workflow architecture, approved environment, student-neutral, or teacher-owned.
- The facilitator can explain direct and indirect identifiers in plain language.
- The facilitator can answer the coded-ID and student-trend questions without implying that replacing names automatically makes data safe.
- The fallback route still produces a useful paper plan if no live tool is available.
- The closing measurement instruction includes normal time, assistant time, correction time, usefulness, and any safety concern.

## Stop conditions

Pause the live build if the school has not named the tool and staff account, a participant opens real student information, or a regulated question cannot be answered by the people in the room. Continue with the supplied practice material while the school resolves the issue.
