# Agent and skill portability

## What each file is

The **Codex skill** is an internal instruction package that helps Andrew or another facilitator consistently apply the Teacher Time Back method while developing examples and answering questions in Codex.

The **platform-neutral agent reference** is a set of instructions, examples, and evaluation cases. It is not a hosted assistant, not a secure school deployment, and not a teacher-facing download.

## Is it only for OpenAI products?

No. The five-part method is vendor-neutral:

1. Help me with
2. Use only
3. Return
4. Stop and ask if
5. I will review

That method can be translated into products that support saved instructions or reusable assistants. The interface, sharing, knowledge, file, retention, and administrative controls differ by product and account type.

Current official product documentation confirms that custom GPTs can use instructions and conversation starters in eligible ChatGPT Business, Enterprise, and Edu workspaces; Gemini Gems can use saved instructions; and Microsoft 365 Copilot Agent Builder can create instruction-based agents when enabled by the organization. MagicSchool is treated as a school-selected teaching platform, but no custom-agent capability is assumed without testing the school's actual account.

Official references:

- OpenAI GPTs: https://help.openai.com/en/articles/8554407-what-are-gpts
- Google Gemini Gems: https://support.google.com/gemini/answer/15235603
- Microsoft 365 Copilot Agent Builder: https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/agent-builder-build-agents

## Adapter rule

Before a pilot, Andrew creates one setup card for the exact product and staff account the school named. He tests the full five-part setup, saving behavior, and first practice result in that account type. He does not promise universal one-click installation or transfer a ZIP directly into a school product.

The first lab can run without uploads, browsing, connectors, memory, or sharing. Leadership decides whether any of those features may be used.
