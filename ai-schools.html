Give teachers time back. One task at a time.

  • No coding
  • No student records
  • One task only

A 90-minute build lab

One small task becomes one working assistant.

No feature tour. No prompt jargon. Each step changes the actual artifact teachers are building.

0-15 MINUTES

Choose a first task that is small enough to succeed.

Teachers name one time drain, then test it against four visible filters.

  • It repeats.
  • It works without student records.
  • The teacher can review it quickly.
  • The job fits in one sentence.

Measure usefulness before deciding to keep it.

The goal is not maximum AI use. Teachers compare time, corrections, usefulness, and safety slips.

  • Revise: the job or output is unclear.
