ANDREW AVATAR ANIMATIONS V1

Copy every file inside assets/ into your portfolio assets folder.

Recommended HTML uses <video> with WebM first, MP4 second, and the matching poster image.
The JavaScript should play the short sequence when it enters the viewport and replay it on hover, focus, or click.
Reduced-motion users will see the poster frame only.
