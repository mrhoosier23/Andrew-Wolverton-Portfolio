ANDREW WOLVERTON PORTFOLIO - FINAL CONSOLIDATED PACKAGE

Use this package as one unit.

1. Open this ZIP.
2. Copy every item inside it into the root of your existing portfolio folder.
3. Choose Replace when Windows asks about matching files.
4. Keep your existing assets folder. This package adds only the corrected iPod image inside assets.
5. Open index.html and hard refresh with Ctrl + Shift + R.
