ABOUT ME GALLERY

1. Place gallery image files in this folder.
2. Open the root script.js file.
3. Find the ABOUT_GALLERY list at the very top.
4. Add one object per image.

Example:

{
  file: "singing-hoosiers-reunion.jpg",
  alt: "Andrew with Singing Hoosiers alumni",
  caption: "Reconnecting with the Singing Hoosiers community."
}

The About page will render the images automatically.
