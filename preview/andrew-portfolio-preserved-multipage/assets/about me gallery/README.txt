ABOUT ME GALLERY

1. Put your image files in this folder.
2. Open script.js.
3. Find const ABOUT_GALLERY.
4. Add one object for each photo.

Example:
{ file: "singing-hoosiers.jpg", alt: "Andrew performing with the Singing Hoosiers", caption: "Performing with the Singing Hoosiers at Indiana University." },

The filename must match exactly, including capitalization and extension.
